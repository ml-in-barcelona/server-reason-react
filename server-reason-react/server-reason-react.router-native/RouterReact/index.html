type blocker =
  1. | Unblocked
  2. | Blocked of {
    1. target : string;
    2. action : RouterRuntime.Navigation.historyAction;
    3. proceed : unit -> unit;
    4. cancel : unit -> unit;
    }

A navigation held by useBlocker. proceed resumes it; cancel drops it and its navigate promise resolves to Canceled.

type invalidation =
  1. | All
  2. | Prefix of RouterRuntime.destination

Which cached navigation responses useInvalidate drops: every entry, or the entries whose path is the destination's path or below it.

type activeWhen =
  1. | Url
  2. | Route
  3. | Subtree

Which locations make a destination active for useIsActive, useIsPending and Link ~activeWhen. Url: the same path and the same search, in any order (the useIsCurrent rule). Route: the same path with any search, so the same route with the same path parameters. Subtree: the same path or a path below it, by whole decoded segments. The hash is always ignored.

Every route active at the committed location, outermost first: the matched route and each route whose path is a prefix of it.

val locationScope : committed:RouterRuntime.Navigation.committed -> children:React.element -> unit -> React.element

Gives Links rendered in server components the committed location, so their aria-current is the same in the Flight payload and in the HTML. The server wraps each routed element with it. In the browser it returns children.

val useInvalidate : unit -> invalidation -> unit

Drops cached navigation responses. Call it after a change on the server that cached pages do not show.

val useIsCurrent : RouterRuntime.destination -> bool

True when the destination has the path and search of the current location, in any query order. The hash is ignored.

val useIsActive : ?activeWhen:activeWhen -> RouterRuntime.destination -> bool

True when the committed location matches the destination by ~activeWhen, Route by default.

val useIsPending : ?activeWhen:activeWhen -> RouterRuntime.destination -> bool

True while a content navigation whose target matches the destination by ~activeWhen (Route by default) is in flight, until its page is on screen. Always false on the server.

val useBlocker : bool -> blocker

While the argument is true, navigate, Link, intercepted clicks, and Back or Forward to other content wait for proceed or cancel.

val outlet : owner:string -> children:React.element -> unit -> React.element
val suspense : fallback:React.element -> children:React.element -> unit -> React.element
val errorBoundary : fallback:React.element -> children:React.element -> unit -> React.element

Renders children, or fallback once rendering children in the browser throws. It shows children again after the next content navigation commits. Generated routes wrap each scope that declares ~error with it.
