Module RouterServer.AdapterSource

Server-agnostic pieces of an HTTP adapter. An adapter parses its request into a ServerEngine.request, calls Server.run, passes the outcome to reply, and writes the reply with its own server. Nothing here depends on an HTTP server.

Sourceval metadata_element : RouterRuntime.Metadata.t -> React.element

Renders resolved metadata as head elements: <title>, <meta name="description">, then each entry as a <meta> or <link> in order. Every element has the stable React key "router:" ^ key. For a Link, attributes named rel or href (any case) in attrs are ignored: the rel and href fields win. The result goes in <head> and is also sent to the client in navigation responses.

Sourceval document_element : (React.element, 'error) Server.t -> pageCacheCapacity:int -> document:(head:React.element -> React.element -> React.element) -> (React.element, 'error) ServerEngine.full -> React.element

Builds the HTML document for a full response. document ~head children builds <html>. head is the metadata element, to be placed inside <head>. children holds the routed root and a marker that tells the client bootstrap whether the server rendered the markup, and goes in <body>.

Sourcetype body =
  1. | Empty
  2. | Html of React.element
    (*

    An HTML document. Render it with the server's bootstrap modules.

    *)
  3. | Model of {
    1. location : string;
    2. model : React.model_value;
    }
    (*

    A navigation response. location is the value for the X-Location header.

    *)
Sourcetype reply = {
  1. status : int;
  2. headers : (string * string) list;
  3. body : body;
}

headers holds every protocol header for the outcome, including Content-Type for Html and Model and Location for redirects. The adapter adds nothing but transport details.

Sourceval reply : (React.element, 'error) Server.t -> target:string -> pageCacheCapacity:int -> document:(head:React.element -> React.element -> React.element) -> kind:ServerEngine.requestKind -> (React.element, 'error) ServerEngine.outcome -> reply

Maps an outcome to status, headers and body. target is the request target, used for X-Location on RSC redirects. kind is the request kind given to Server.run. Every reply carries Vary: Accept.

  • Full and patch: the resolved status and headers.
  • Document redirect: 303 (Redirect) or 308 (PermanentRedirect) with Location.
  • RSC redirect: 200 with Router-Response: redirect, Router-Registry and Cache-Control: private, no-store.
  • ReloadRequired: 409 with Router-Response: reload-required and Cache-Control: private, no-store.
