Module RouterServer.ServerEngineSource

The request-level state machine.

Document requests always produce complete render data. RSC navigations may instead reuse the common prefix of the previous and target branches. A registry mismatch requests a reload before any route loaders run.

  4. revision : string;
  5. registry_fingerprint : string;
  6. protocol_version : int;

  9. replace_from : string;

}
Sourcetype ('view, 'error) outcome =
  1. | Full of ('view, 'error) full
  2. | Patch of ('view, 'error) patch
  3. | ReloadRequired
  4. | Redirect of RouterRuntime.destination
    (*

    A navigation redirect requested by a route loader. Adapters answer with a see-other response.

    *)
  5. | PermanentRedirect of RouterRuntime.destination
    (*

    A pathname canonicalization redirect. Adapters answer documents with status 308 so the request method survives the redirect.

    *)
Sourceval run : registry:(('view, 'error) Plan.t, 'error) EndpointRegistry.t -> basePath:string -> trailingSlash:TrailingSlash.t -> fallback: (search:Search.t -> error:'error RouterRuntime.Error.t -> ('view, 'error) Plan.t) -> applicationStatus:('error -> RouterRuntime.Status.t) -> diagnosticId:(exn -> string) -> revision:(unit -> string) -> protocolVersion:int -> request -> ('view, 'error) outcome Lwt.t

Validates and matches the request, executes its loaders, resolves the resulting plan, and chooses the smallest safe outcome. Unexpected exceptions are offered to the root fallback before a blank internal-error response is used as a last resort.
