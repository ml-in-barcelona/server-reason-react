Module RouterEngineSource

Used by generated Router.ml, RouterRegistry.ml and RouterServer. Not a stable API: applications use RouterServer.

The server router turns an HTTP location into a renderable response in stages.

Path and Search first validate the untrusted URL. Registry and Match select a route, then Decode gives the generated endpoint typed inputs. The endpoint describes both its reusable layout Branch and its deferred loader Execution. Finally, Plan assembles the view, metadata, and headers while ServerEngine decides whether the client needs a full response, a branch patch, a redirect, or a reload.
